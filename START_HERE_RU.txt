КОНТР КУЛЬТ — ВЕРСИЯ ДЛЯ WINDOWS 10 x64, 31.10.2026

ПЕРВЫЙ ЗАПУСК

1. Распакуйте ZIP целиком через «Извлечь всё». Поместите всю папку игры
   на локальный диск в доступную для записи папку вашего пользователя.
   Не запускайте игру прямо из открытого ZIP и не переносите отдельно EXE.
2. Дважды щёлкните 1_Install.cmd. Установщик проверит EXE и 12 библиотек,
   восстановит отсутствующие/повреждённые файлы из локального runtime.zip
   и проверит загрузку DLL. Дождитесь сообщения Ready.
3. Откройте 2_Play.cmd. В дальнейшем используйте этот файл.
   Ikemen_GO.cmd — такой же запуск. При необходимости он также восстанавливает
   библиотеки из локального архива.

Все нужные сторонние DLL уже включены. Установка работает без интернета
и без прав администратора; отдельный менеджер пакетов не требуется.
Установщик использует стандартный Windows PowerShell из состава Windows 10.
Библиотеки размещаются в папке lib рядом с игрой. Повреждённые старые файлы
перед восстановлением сохраняются в windows_support/backups.

ТРЕБОВАНИЯ К КОМПЬЮТЕРУ

- Windows 10, 64-разрядная версия, процессор Intel или AMD x64.
  Эта сборка не предназначена для 32-разрядной Windows и Windows ARM.
- Видеокарта и её драйвер с поддержкой OpenGL 3.3.
- Для первого запуска нужна возможность записи в папку игры.

На только что установленной Windows может потребоваться драйвер видеокарты.
Если появляется ошибка OpenGL / graphics context, установите драйвер через
Windows Update или с официального сайта производителя видеокарты/ноутбука.
Универсального драйвера для всех видеокарт в этом комплекте нет.
Затем снова откройте 2_Play.cmd. Для проверки в оконном режиме можно открыть
командную строку в папке игры и выполнить: 2_Play.cmd -windowed

ЕСЛИ WINDOWS БЛОКИРУЕТ ОТКРЫТИЕ

Если SmartScreen показывает «Система Windows защитила ваш компьютер»,
для полученной от друга игры можно выбрать «Подробнее» → «Выполнить в любом
случае». Защиту Windows целиком отключать не требуется. Если на рабочем
компьютере запуск запрещён политиками организации, обратитесь к её администратору.

КАК ИГРАТЬ ВДВОЁМ ПО ЛОКАЛЬНОЙ СЕТИ

Нужны одинаковые игровые ресурсы и версия движка v1.0.0-rc.5 у обоих игроков.
Ресурсы этой копии соответствуют текущей Mac-игре и подготовленной
KK_Game_AirDrop (копия от 31.10.2026). Изменения после сборки автоматически не переносятся.

1. Подключитесь к одной обычной Wi-Fi или проводной сети. Гостевая сеть
   может запрещать компьютерам соединяться друг с другом.
2. Первый игрок выбирает NETWORK → HOST GAME.
3. Второй: NETWORK → JOIN GAME → NEW ADDRESS, затем вводит локальный IPv4
   первого компьютера. На Windows его можно узнать командой ipconfig:
   нужен IPv4 активного Wi-Fi/Ethernet, а не 127.0.0.1.
4. После соединения выберите VERSUS 2P.
   Если брандмауэр запросит разрешение для игры, разрешите соединение
   в вашей частной сети. Используемый в игре порт — 7500.

Для игры из разных сетей потребуются дополнительные настройки соединения.
Сетевой бой между Mac и Windows пока не был проверен на двух компьютерах.

УПРАВЛЕНИЕ

Игрок 1: стрелки; Z/X/C и A/S/D — удары; Enter — Start.
Игрок 2 на одной клавиатуре: I/J/K/L; F/G/H и R/T/Y; правый Shift — Start.
Esc — меню / назад. Настройки кнопок и геймпадов находятся в OPTIONS.

ЕСЛИ НЕ РАБОТАЕТ

Отправьте создателю игры файлы из windows_support:
- setup-windows.log — установка;
- game-windows.stdout.log и game-windows.stderr.log — последний запуск.

Можно открыть командную строку в папке игры и выполнить:
  1_Install.cmd -Check
или:
  2_Play.cmd -Check
Проверка не устанавливает файлы и не запускает игру. Она проверяет
целостность EXE/DLL и загрузку библиотек, но не возможности видеокарты.

Если отсутствует персонаж, сцена или другой файл ресурсов, заново распакуйте
полный ZIP. Локальный runtime.zip предназначен для восстановления EXE/DLL.
Если восстановление DLL не удаётся, закройте игру перед повторной установкой.
