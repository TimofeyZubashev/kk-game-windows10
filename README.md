# Контр Культ — Windows 10 x64

Готовая Windows-копия игры на Ikemen GO v1.0.0-rc.5 с персонажами, сценами,
музыкой и меню из нашего проекта. EXE и все 12 DLL включены в репозиторий.
Git LFS для скачивания этой версии не требуется.

## Скачать и запустить

1. На странице репозитория нажмите **Code → Download ZIP** либо клонируйте
   репозиторий через GitHub Desktop на Windows.
2. Распакуйте **весь** ZIP в доступную для записи папку вашего пользователя.
3. Откройте **`1_Install.cmd`** и дождитесь сообщения `Ready`.
4. Откройте **`2_Play.cmd`**.

Установщик проверяет EXE/DLL по SHA-256 и при необходимости восстанавливает
их из включённого `windows_support/runtime.zip`. Для библиотек интернет
и права администратора не требуются. Нужна Windows 10 x64 на Intel/AMD
и видеокарта с драйвером, поддерживающим OpenGL 3.3.

Подробная инструкция, управление, настройка сетевого боя и разбор ошибок —
в [START_HERE_RU.txt](START_HERE_RU.txt).

## Совместная игра

В меню выберите **NETWORK → HOST GAME** на первом компьютере и
**NETWORK → JOIN GAME → NEW ADDRESS** на втором. Для локальной сети
используйте IPv4 первого компьютера. Порт в конфигурации — `7500`.
Обоим нужны одинаковые версии движка и игровых ресурсов.

Игровые ресурсы этой версии сверены с подготовленной Mac-копией от
31 октября 2026 года. Проверены файлы и логика установщика; настоящий запуск
на Windows, графика и сетевой бой Mac ↔ Windows пока не проверены.
